# Highway Racer 🏎️

An endless browser-based racing game developed with vanilla JavaScript, featuring dynamic difficulty scaling, collision detection, and keyboard controls.

## 🛠 Tech Stack
* **Languages**: HTML5, CSS3, JavaScript (ES6+)

## ✨ Core Features
* **Collision Detection Engine**: Real-time bounding-box detection handling player and vehicle hitboxes.
* **Keyboard Control Integration**: Multi-key listener events for fluid steering and acceleration.
* **Dynamic Score Tracking**: Incremental scoring system that scales dynamically with survived game time.
* **Optimized Frame Rendering**: Smooth animation loop ensuring steady 60fps across modern web browsers.
* **Modular Codebase**: Componentized gameplay modules built for simple maintenance and feature expansion.
